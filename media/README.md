# Rebuild the demonstration

These are actual application captures, the original narration script, and the media pipeline. The video discloses edited application captures and synthetic narration. TTS uses en-US-AndrewMultilingualNeural through edge-tts; it does not clone the builder’s voice. There is no background music.

Create a Python environment, install requirements.txt, run generate_voice.py and then render.py. Audio, word timestamps, caption panels, SRT, timeline and MP4 are written to ignored generated/. The renderer uses actual word-boundary timing and checks the three-minute limit. Final duration: 156.818 seconds. A user must audition the full artifact for pronunciation and emotional delivery before publication.
